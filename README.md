# Mini Project Flutter - Profil & Portofolio

Aplikasi mobile / web sederhana satu halaman (*Single Page App*) yang dibuat menggunakan framework Flutter untuk memenuhi tugas mata kuliah Teknik Informatika.

## Fitur & Komponen yang Digunakan:
- **Widget Dasar:** `Text`, `Image.asset`, `Icon`
- **Widget Layout:** `Column`, `Row`, `SingleChildScrollView`
- **Styling:** `Container` dengan dekorasi lingkaran dan border
- **Informasi:** `Card` & `ListTile`
- **Tema:** Global `ThemeData`

## Pembuat:
- **Nama:** Syifa Lutfia Aulia
- **Kelas:** Teknik Informatika - Kelas Karyawan
